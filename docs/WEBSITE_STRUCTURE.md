# Website Structure

## 1. Navigation
- Logo / Name
- About
- Experience
- Projects
- Skills
- Contact

## 2. Hero
Must immediately communicate:
- Name
- Role positioning
- Short value proposition
- Primary CTA
- Secondary CTA

Suggested positioning:
"Turning data into insights that drive better business decisions."

## 3. About
Focus on:
- Engineering background
- Transition into analytics
- Analytical approach
- Business curiosity

## 4. Skills
Display grouped skills rather than generic percentage bars.

Suggested groups:
- SQL & Databases
- Python & Analysis
- Business Intelligence
- Business Analytics

## 5. Experience
Use a clean timeline or editorial layout.

Highlight measurable impact.

## 6. Featured Projects
The most important portfolio section.

Each project card should show:
- Project title
- Business problem
- Tools used
- Key insight
- CTA to detailed case study

## 7. Project Case Study
Recommended structure:
1. Context
2. Problem
3. Dataset
4. Analysis
5. Key Insights
6. Recommendations
7. Tools

## 8. Contact
Include:
- LinkedIn
- GitHub
- Email
- Resume CTA

## 9. Footer
Simple and minimal.
