# Project Brief

## Project
Personal Data Analytics Portfolio Website for Farhan Khan.

## Primary Goal
Create a premium, memorable, and highly professional portfolio website that helps Farhan stand out when applying for:
- Data Analyst roles
- Business Analyst roles
- Product Analyst roles
- Analytics-related roles

## Target Audience
1. Recruiters
2. Hiring Managers
3. Startup founders
4. Analytics managers
5. Product teams

## Core Positioning
Farhan is an aspiring data and business analyst with an engineering background.

The portfolio should communicate that he can:
- Work with messy datasets
- Extract meaningful insights
- Use SQL and Python for analysis
- Build dashboards
- Understand business metrics
- Translate analysis into actionable recommendations

## Important Differentiation
Do NOT make this look like a generic software developer portfolio.

The portfolio should feel like the website of someone who thinks in:
- Metrics
- Business problems
- Customer behavior
- Revenue
- Products
- Data-driven decisions

## Design Personality
Premium, modern, analytical, minimal, confident, intelligent, editorial.

Avoid:
- Generic portfolio templates
- Excessive gradients
- Random floating blobs
- Too much glassmorphism
- Excessive animations
- Fake statistics
- Skill percentage bars
- Overly colorful dashboards

## User Journey
A recruiter should understand within 30 seconds:
1. Who is Farhan?
2. What roles is he targeting?
3. What analytical skills does he have?
4. What projects has he completed?
5. Can he solve business problems with data?
6. Where can they contact him?

## Primary CTAs
- View Projects
- Download Resume
- Connect on LinkedIn

## Technical Requirements
- Fully responsive
- Mobile-first
- Fast loading
- Accessible
- Clean navigation
- SEO-friendly
- Smooth but subtle interactions

## Content Rule
Never invent companies, job titles, metrics, certifications, project results, or awards.
Use only verified information from the documentation files.
